# Tietoturva

Älä julkaise tietoturvahavaintoja avoimena GitHub-issuena.

Toimita havainto projektin omistajalle yksityisesti. Liitä mukaan:

- haavoittuva reitti tai komponentti
- toistamisvaiheet
- arvioitu vaikutus
- mahdollinen korjausehdotus

Älä liitä viestiin asiakkaiden henkilötietoja, tuotantotunnuksia tai salaisuuksia.
